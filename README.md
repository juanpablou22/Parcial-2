## 🛠️ Especificaciones Técnicas

### 1. Arquitectura HTML5 Semántica
Se implementó una estructura limpia para garantizar accesibilidad y SEO técnico:
* `<nav>`: Navegación principal del sitio.
* `<header>`: Sección de impacto (Banner principal).
* `<main>`: Contenedor de las secciones core: *Shop, Disney+, Movies y Parks*.
* `<article>`: Utilizado para las tarjetas de productos y destacados, permitiendo independencia del contenido.
* `<footer>`: Información legal y enlaces secundarios.

### 2. Estrategias de Estilizado (CSS3)
* **Box Model:** Uso de `border-box` para cálculos de dimensiones exactos.
* **Flexbox Layout:** Implementado en la navbar y contenedores de tarjetas para alineación dinámica.
* **Diseño Adaptativo:** Uso de unidades relativas (`rem`, `vh`, `%`) y `background-size: cover` para asegurar que las imágenes se ajusten a cualquier pantalla.
* **Micro-interacciones:** Transiciones suaves en botones y enlaces para mejorar la experiencia de usuario (UX).

## 🚀 Propuestas de Mejora (Roadmap)
Para elevar la calidad del código en futuras entregas, se proponen:
1.  **Variables CSS:** Centralizar colores y espaciados mediante `:root`.
2.  **CSS Grid:** Para el manejo de las galerías de películas y parques.
3.  **Tipografía Fluida:** Implementación de `clamp()` para textos que escalan sin necesidad de tantos *media queries*.
4.  **Metodología BEM:** Organización de clases bajo el estándar `bloque__elemento--modificador`.
